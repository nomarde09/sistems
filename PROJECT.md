# PROJECT: Система заявок

Простая система заявок для компании по монтажу камер видеонаблюдения и автоматических ворот.

## Зачем

Сейчас заявки дают руководитель и два менеджера, работают две бригады, и непонятно, кто какую заявку взял, выполнил и когда. Система должна давать один ответ на вопросы: кто создал заявку, какая бригада её взяла, когда выполнила и за сколько.

## Кто пользуется (5 входов)

| Вход | Что может |
|---|---|
| Руководитель | Создаёт заявки, видит все, ищет, **исправляет и отменяет** заявки |
| Менеджер 1, Менеджер 2 | Создают заявки, видят все, ищут |
| Бригада 1, Бригада 2 | Видят свободные заявки, берут их, **могут вернуть** в свободные, пишут отчёт |

Вход: выбрать себя на странице входа и ввести короткий пароль (4 цифры). Устройство запоминает вход. Пароли хранятся в файле `.env`, в репозиторий он не попадает.

## Заявка

Заполняет руководитель или менеджер:
- имя клиента, телефон, адрес
- что монтируем: менеджер пишет своими словами (без выбора из списка)
- на какой день договорились с клиентом
- срочная или нет
- описание работ

Обязательные поля: имя, телефон, адрес, что монтируем, описание. День необязателен, его может ещё не быть.

Автоматически записывается: кто создал, когда создана. В общем списке сверху идут новые, потом в работе, потом остальные; срочные внутри каждой группы первыми.

Отчёт бригады после работы: что сделано, **цена (одна общая сумма)**, комментарий. Дата выполнения ставится сама.

## Статусы

```
Новая ──(бригада взяла)──► В работе ──(отчёт)──► Выполнена
  ▲                          │
  └──(бригада вернула)───────┘

Новая / В работе ──(руководитель отменил)──► Отменена
```

Когда бригада взяла заявку, вторая бригада её больше не видит в свободных. Если обе нажмут «Взять» одновременно, заявка достанется только одной.

У бригады две вкладки: «Свободные» и «Мои заявки», с числом заявок в каждой. Свободные идут так: срочные первыми, потом по ближайшему дню, без дня в конце.

**Журнал.** Каждое действие с заявкой (создал, взяла, вернула, выполнила, исправил, отменил) записывается: кто и когда. Журнал виден руководителю и менеджерам в карточке заявки, поэтому, даже если заявку вернули и её взяла другая бригада, видно, кто брал её раньше.

## Как устроено

Маленький сайт, который открывается в браузере на компьютере и на телефоне.
- Программа: Python + Flask, файл `app.py`.
- Данные: один файл базы SQLite (`data/zayavki.db`).
- Страницы: вход; для руководителя и менеджеров; для бригад.

## Этапы

После каждого этапа Claude сам проверяет сайт в браузере и сообщает, что можно посмотреть.

- [x] Репозиторий, `.gitignore`, описание проекта
- [x] **1. Вход.** 5 входов с паролем, у каждого своя страница
- [x] **2. Создание заявки.** Форма, общий список со статусом «Новая» и автором
- [x] **3. Бригада берёт заявку.** «Свободные», «Взять», «Вернуть»; защита от взятия двумя бригадами
- [ ] **4. Отчёт.** Что сделано, цена, комментарий → «Выполнена» + дата
- [ ] **5. Руководитель: исправить и отменить заявку.** Поиск и фильтры: по клиенту, адресу, телефону, статусу, бригаде, автору, датам
- [ ] **6. Телефон.** Удобство на маленьком экране, проверка всего пути целиком
- [ ] **7. Интернет.** Размещение на хостинге (нужно участие владельца), ограничение попыток ввода пароля, удалить примеры заявок, выставить часовой пояс (`TZ_OFFSET_HOURS` в `.env`; сервер хостинга обычно живёт по UTC)

## Пока не делаем

- Уведомления (СМС, Телеграм, почта)
- Фотографии с объекта
- Учёт оплаты, долгов, зарплат; цена разбивкой на работу и материалы (добавим позже)
- Склад и материалы
- Графики, отчёты, выгрузка в Excel
- Отдельная база клиентов
- Отдельный вход для каждого монтажника
- Назначение заявки на бригаду руководителем
- Приложение в магазине приложений
