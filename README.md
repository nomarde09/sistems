# Система заявок

Простая система заявок для компании по монтажу камер видеонаблюдения и автоматических ворот. Руководитель и менеджеры создают заявки, бригады берут их и отчитываются о выполнении, и всегда видно, кто что взял, когда сделал и за сколько.

> Статус: готовы этапы 1–4 из 7 (вход, создание заявок, бригады берут заявки, отчёт о выполнении). План в [PROJECT.md](PROJECT.md).

## Как работает

- Руководитель или менеджер создаёт заявку: клиент, адрес, телефон, что монтируем (своими словами), дата, срочность, описание.
- Бригада видит свободные заявки и берёт одну; у второй бригады она пропадает.
- После работы бригада пишет отчёт: что сделано, цена, комментарий.
- Статусы: «Новая» → «В работе» → «Выполнена» (руководитель может отменить).

## Начало работы

Нужен Python 3.

```bash
git clone git@github.com:nomarde09/sistems.git
cd sistems
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python app.py
```

Сайт откроется на http://localhost:5000. При первом запуске сам создастся файл `.env` с паролями входа.
