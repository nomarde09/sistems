# Система заявок

Приложение для приёма, учёта и обработки заявок: создание заявки, назначение исполнителя, отслеживание статуса до закрытия.

> Статус: проект на начальной стадии. Код ещё не добавлен, стек технологий не выбран.

## Возможности (план)

- Создание заявки с описанием, категорией и приоритетом
- Назначение ответственного исполнителя
- Статусы заявки: новая → в работе → выполнена / отклонена
- История изменений и комментарии к заявке
- Поиск и фильтрация заявок
