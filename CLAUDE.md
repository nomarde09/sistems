# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## О проекте

«Система заявок»: приложение для приёма и обработки заявок. Цели, роли, модель данных и план работ описаны в [PROJECT.md](PROJECT.md). Перед крупными изменениями сверяйся с ним, а после выполнения пункта плана отмечай его там.

Пользователь не программист. Всю техническую работу (код, установка, запуск, тесты, исправления) делает Claude. Не давай пользователю инструкций вида «создай файл» или «запусти команду». Если без его действия не обойтись (хостинг, оплата), объясни по шагам простыми словами.

После каждого этапа из PROJECT.md: сам проверь работу (автотесты и браузер), затем коротко напиши, что можно посмотреть и как открыть.

Стек выбран: Python + Flask, данные в SQLite. Новые зависимости и крупные смены подхода сначала согласуй с пользователем.

## Общение

- Пиши пользователю на русском языке, простыми словами.
- Перед заметными действиями коротко объясняй, что собираешься сделать.

## Git

- Удалённый репозиторий: `git@github.com:nomarde09/sistems.git`, основная ветка `main`.
- Коммить и пушь только по просьбе пользователя.
- Сообщения коммитов короткие и по делу; можно на английском или русском, но в одном стиле.
- Не коммить секреты: `.env`, ключи, пароли. Для примеров настроек используй `.env.example`.

## Структура

```
app.py             — вся программа: входы, страницы, правила доступа
templates/         — страницы (HTML-шаблоны Jinja)
tests/             — автопроверки (unittest)
static/style.css   — оформление
requirements.txt   — зависимости
.env               — секретный ключ и пароли входа (создаётся сам, не в git)
.env.example       — пример .env
data/              — база заявок (не в git)
.claude/launch.json — запуск для превью в Claude Code (имя "zayavki")
```

Пользователи заданы в `USERS` в `app.py`, роли: `boss` (руководитель), `office` (менеджер), `brigade` (бригада). Пароли: `PIN_<ID>` в `.env`. Адреса страниц на латинице транслитом: `/vhod`, `/ofis`, `/brigada`.

## Команды

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python app.py        # сайт на http://localhost:5000
.venv/Scripts/python -m unittest discover -s tests -v   # автопроверки
```

Автопроверки (`tests/test_app.py`) работают на временной базе. После каждого изменения прогоняй их, на каждый новый этап добавляй свои. Все формы с POST должны содержать скрытое поле `csrf` (`{{ csrf_token() }}`), иначе сервер ответит 400.

Время хранится как местное, пояс задаёт `TZ_OFFSET_HOURS` в `.env`. После правки `.env` сайт нужно перезапустить целиком (остановить и запустить превью), автоперезагрузка его не перечитывает.

Для проверки в браузере используй превью `zayavki`. Не показывай пароли из `.env` в чате, отсылай пользователя к файлу.
