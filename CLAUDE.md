Инструкции для Claude Code при работе с этим репозиторием.

## О проекте

«Система заявок»: приложение для приёма и обработки заявок. Цели, роли, модель данных и план работ описаны в [PROJECT.md](PROJECT.md). Перед крупными изменениями сверяйся с ним, а после выполнения пункта плана отмечай его там.

Сейчас проект на начальной стадии: кода нет, стек не выбран. Не выбирай стек самостоятельно, сначала предложи варианты и дождись решения пользователя.

## Общение

- Пиши пользователю на русском языке, простыми словами.
- Перед заметными действиями коротко объясняй, что собираешься сделать.

## Git

- Удалённый репозиторий: `git@github.com:nomarde09/sistems.git`, основная ветка `main`.
- Коммить и пушь только по просьбе пользователя.
- Сообщения коммитов короткие и по делу; можно на английском или русском, но в одном стиле.
- Не коммить секреты: `.env`, ключи, пароли. Для примеров настроек используй `.env.example`.
